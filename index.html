📖 如何使用

1 安装扩展

  1. 点击上方 "下载 Edge 扩展" 按钮
  2. 跳转到 Edge 扩展商店页面
  3. 点击右侧 "获取" → "添加扩展"
  4. 安装完成后，浏览器右上角会出现扩展图标
💡 安装后无需额外设置，打开 DeepSeek 即可使用

2 单轮导出

  1. 打开 DeepSeek 对话页面
  2. 每条 AI 回答下方会自动出现导出按钮：
    Markdown / HTML / JSON / Word
  3. 点击 "···" 更多按钮，可选择：
    PDF / PNG / TXT / ipynb
  4. 点击对应按钮即可下载该轮对话
💡 鼠标悬停按钮会显示格式说明

3 批量导出

  1. 点击页面右上角蓝色按钮
    "导出多轮对话"
  2. 弹出对话框，勾选需要导出的内容：
    全部信息 / 仅提问 / 仅回答 / 仅思考
  3. 选择导出格式（八种任选）
  4. 点击 "确定导出" 即可下载整个话题
💡 支持 100+ 轮超长会话完整导出
